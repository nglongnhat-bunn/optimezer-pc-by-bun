# LongNhat

A Windows PC optimizer and debloater tool.

## Features
- System tweaks & optimization
- Debloat Windows
- DNS Manager
- App installer
- System cleaner

## Install
Download the latest release from [Releases](https://github.com/nglongnhat-bunn/optimezer-pc-by-bun/releases)

## Build from source
```powershell
git clone https://github.com/nglongnhat-bunn/optimezer-pc-by-bun
cd optimezer-pc-by-bun
pnpm i
pnpm dev
```
